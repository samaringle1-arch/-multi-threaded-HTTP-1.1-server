It works.

A multi-threaded HTTP/1.1 server built from scratch in C. No libraries. No frameworks. Just POSIX.

What's running right now

  • TCP socket server — raw BSD sockets, accept loop, SIGINT shutdown
  • HTTP/1.1 parser — state machine, partial read handling, 40 unit tests
  • Thread pool — 4 workers, mutex + condition variable work queue, graceful drain
  • Static file server — sendfile(2) zero-copy, MIME types, path traversal protection
  • Keep-alive — persistent connections, SO_RCVTIMEO idle timeout, pipelining
  • Chunked encoding — Transfer-Encoding: chunked for unknown-length responses
